# 2x2 매트릭스 빌더

브라우저에서 바로 쓰는 2x2 매트릭스(사분면) 빌더입니다. 빌드나 설치 없이 `index.html` 파일 하나로 동작합니다.

## 사용법

- `index.html`을 브라우저로 열면 바로 시작할 수 있습니다.
- 또는 GitHub Pages 등 정적 호스팅에 그대로 올려서 사용할 수 있습니다.

## 기능

- **제목 / 축 라벨 편집**: 매트릭스 제목, 가로축(X)·세로축(Y) 이름과 양 끝 라벨을 자유롭게 수정
- **사분면 커스터마이즈**: 4개 사분면의 이름과 배경색을 각각 지정
- **항목 추가/편집/삭제**: 텍스트와 색상을 지정해 항목(카드)을 추가하고, 매트릭스 위에서 드래그로 자유롭게 배치
- **자동 저장**: 모든 변경 사항은 브라우저 `localStorage`에 자동 저장되어 새로고침해도 유지
- **초기화**: 기본 예시(아이젠하워 매트릭스)로 되돌리기
- **JSON 내보내기 / 가져오기**: 작업 내용을 JSON 파일로 저장하고 다시 불러오기
- **이미지로 저장**: 완성한 매트릭스를 PNG 이미지로 내보내기

기본값은 "긴급도 vs 중요도" 아이젠하워 매트릭스 예시로 채워져 있으며, 모든 라벨/항목을 자유롭게 바꿔 임의의 2x2 프레임워크(임팩트-노력 매트릭스 등)로 활용할 수 있습니다.

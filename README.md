# 2x2 매트릭스 빌더 & 저널링 프롬프트 캔버스

브라우저에서 바로 쓰는 정적 웹 도구 모음입니다. 빌드나 설치 없이 HTML 파일 하나로 동작합니다.

- `index.html` — 2x2 매트릭스(사분면) 빌더
- `journal.html` — 공익활동 회고를 위한 저널링 프롬프트 캔버스

## 2x2 매트릭스 빌더 (`index.html`)

## 사용법

- `index.html`을 브라우저로 열면 바로 시작할 수 있습니다.
- 또는 GitHub Pages 등 정적 호스팅에 그대로 올려서 사용할 수 있습니다.

## 기능

- **템플릿으로 시작하기**: 자주 쓰는 2x2 프레임워크 11종을 선택하면 축 라벨·사분면·예시 항목이 즉시 채워짐 (아래 목록 참고)
- **제목 / 축 라벨 편집**: 매트릭스 제목, 가로축(X)·세로축(Y) 이름과 양 끝 라벨을 자유롭게 수정
- **사분면 커스터마이즈**: 4개 사분면의 이름과 배경색을 각각 지정
- **항목 추가/편집/삭제**: 텍스트와 색상을 지정해 항목(카드)을 추가하고, 매트릭스 위에서 드래그로 자유롭게 배치
- **자동 저장**: 모든 변경 사항은 브라우저 `localStorage`에 자동 저장되어 새로고침해도 유지
- **초기화**: 기본 예시(아이젠하워 매트릭스)로 되돌리기
- **JSON 내보내기 / 가져오기**: 작업 내용을 JSON 파일로 저장하고 다시 불러오기
- **이미지로 저장**: 완성한 매트릭스를 PNG 이미지로 내보내기

기본값은 "긴급도 vs 중요도" 아이젠하워 매트릭스 예시로 채워져 있으며, 모든 라벨/항목을 자유롭게 바꿔 임의의 2x2 프레임워크로 활용할 수 있습니다.

### 내장 템플릿

**업무/생산성**
- 아이젠하워 매트릭스 (긴급도 × 중요도)
- 노력-효과 매트릭스 (실행 노력 × 기대 효과)
- 위임 매트릭스 (내 역량 × 업무 중요도)

**전략/기획**
- BCG 매트릭스 (시장 점유율 × 시장 성장률)
- Ansoff 매트릭스 (제품 × 시장)
- TOWS 매트릭스 (강점·약점 × 기회·위협)

**아이디어 평가**
- 가치-실현가능성 매트릭스 (사용자 가치 × 구현 용이성)
- 비용-가치 매트릭스 (백로그 우선순위)

**개인 성찰/의사결정**
- 감정-에너지 매트릭스 (감정 체크인)
- 관심-영향력 매트릭스 (이해관계자 분석)

**학습/역량 개발**
- 숙련도-중요도 매트릭스 (디지털 역량 자가진단)

## 저널링 프롬프트 캔버스 (`journal.html`)

공익활동/시민단체 회고에 맞춰 설계한 저널링 도구입니다. 개인 감정뿐 아니라 **활동의 사회적 맥락과 지속가능성**까지 다루도록 6개 카테고리의 프롬프트를 제공합니다.

### 사용법

- `journal.html`을 브라우저로 열면 바로 시작할 수 있습니다.
- 또는 GitHub Pages 등 정적 호스팅에 그대로 올려서 사용할 수 있습니다.

### 기능

- **6개 카테고리 프롬프트**: 활동 회고(사실 기반) · 임팩트 성찰 · 관계와 협업 · 소진(번아웃) 체크 · 구조적 원인 탐색 · 다음 행동으로 연결
- **회고 유형별 구성**: "전체 회고" / "프로젝트 종료 후 회고"(1·2번 중심) / "정기 회고 · 월간·분기별"(4·5번 중심) / "가볍게 시작"(구조적 원인 탐색 제외, 개인 성찰용)으로 전환하면 핵심 카테고리가 펼쳐지고 나머지는 접혀서 정리됨
- **개인 vs 조직 공유 태그**: 소진 체크는 🔒 개인 전용, 구조적 원인 탐색은 🏛️ 조직 공유용으로 구분 표시
- **후속 질문 체인**: 구조적 원인 탐색 답변 뒤에 "그럼 이걸 누구에게, 어떻게 전달할 수 있을까요?"라는 실행 연결 질문이 자동으로 이어짐
- **여러 회고 저장/관리**: 활동명·날짜별로 회고를 여러 건 저장하고 목록에서 불러오기/삭제
- **자동 저장**: 모든 변경 사항은 브라우저 `localStorage`에 자동 저장되어 새로고침해도 유지
- **작성 진행률 표시**: 현재 회고 유형 기준으로 몇 문항을 작성했는지 실시간 표시
- **내보내기**: 마크다운(전체 / 개인 항목을 제외한 조직 공유용), 클립보드 복사, 전체 백업 JSON 내보내기·가져오기, 인쇄/PDF 지원
